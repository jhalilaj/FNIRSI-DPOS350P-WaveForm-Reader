# Reference captures for final validation

Use a source with a known frequency and voltage. Record how those values are known. Keep the probe factor on the probe and in the scope settings matched.

1. Save a grounded-input capture and its screenshot. Record coupling, probe factor, volts/div and time/div.
2. Save a stable known DC level and its screenshot, using the same vertical settings as step 1.
3. Save a known-frequency square wave and its screenshot. Include source amplitude, DC offset and frequency.
4. Stop that acquisition. Change only volts/div and save again. Then change only time/div and save again. Clearly label these as changes to a held acquisition.
5. Repeat the known signal with CH2 alone, then both channels enabled.

Save WAV and screenshot from each same stopped acquisition before changing settings. Give the paired files matching descriptive names, since the scope's automatic screenshot and waveform counters are independent.
